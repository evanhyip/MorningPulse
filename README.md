**Autonomous Executive Telemetry & Root-Cause Intelligence Engine**  
*Built for Cal Hacks 13.0 · Targeting Best Use of Snowflake API & Enterprise Intelligence Tracks*

---

## 📌 Overview

**MorningPulse** transforms noisy enterprise time-series telemetry into prioritized, actionable executive intelligence. Instead of forcing leaders to dig through sprawling dashboards or relying on LLMs to perform unreliable raw statistical math, MorningPulse combines:

1. **Deterministic Statistical Detection**: A rolling Z-score baseline engine that isolates legitimate operational outliers.
2. **Context Correlation**: Cross-references anomalous metrics against deployment logs, infrastructure traces, and vendor status events.
3. **Snowflake Cortex Synthesis**: Leverages Snowflake's `AI_COMPLETE` REST API (`llama3.1-8b`) to isolate the smoking gun, calculate business impact, and draft autonomous remediation checklists.
4. **Human-in-the-Loop Action UI**: An executive dashboard with staged triggers (e.g., service rollbacks, incident broadcasts).
